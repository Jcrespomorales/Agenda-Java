# Agenda de Contactos - Java

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Jcrespomorales/Agenda-Java)

## 🚀 Características

- Añadir nuevos contactos con nombre, teléfono y correo electrónico
- Buscar contactos por nombre
- Editar información existente
- Eliminar contactos
- Guardar los datos en archivo local

## 🛠️ Tecnologías

- Java 
- Programación orientada a objetos

## 💻 Cómo acceder a GitHub Codespaces

GitHub Codespaces te permite trabajar con este proyecto directamente desde tu navegador, sin necesidad de instalar nada en tu computadora.

### Opción 1: Usar el botón "Open in GitHub Codespaces"

1. Haz clic en el botón **"Open in GitHub Codespaces"** al inicio de este README
2. Espera a que se cree y configure tu entorno de desarrollo (puede tomar 1-2 minutos)
3. Una vez listo, tendrás VS Code en tu navegador con Java ya instalado

### Opción 2: Crear Codespace desde el repositorio

1. Ve al repositorio en GitHub: https://github.com/Jcrespomorales/Agenda-Java
2. Haz clic en el botón verde **"Code"** 
3. Selecciona la pestaña **"Codespaces"**
4. Haz clic en **"Create codespace on main"** (o en la rama que desees)
5. Espera a que se configure el entorno

### Opción 3: Desde la página de GitHub Codespaces

1. Ve a https://github.com/codespaces
2. Haz clic en **"New codespace"**
3. Selecciona el repositorio **"Jcrespomorales/Agenda-Java"**
4. Elige la rama y la configuración
5. Haz clic en **"Create codespace"**

## 🏃‍♂️ Cómo ejecutar la aplicación en Codespaces

Una vez que tu Codespace esté listo:

1. Abre la terminal en VS Code (Terminal → New Terminal)
2. Compila el programa:
   ```bash
   javac AgendaContactos.java Contactos.java
   ```
3. Ejecuta el programa:
   ```bash
   java AgendaContactos
   ```
4. ¡Usa la agenda de contactos desde la terminal!

## 📝 Nota sobre Codespaces

- Los Codespaces son gratuitos con límites de uso mensual para cuentas personales de GitHub
- Tu Codespace se detiene automáticamente después de 30 minutos de inactividad
- Puedes acceder a tus Codespaces desde https://github.com/codespaces
- Los cambios se guardan automáticamente en tu Codespace
